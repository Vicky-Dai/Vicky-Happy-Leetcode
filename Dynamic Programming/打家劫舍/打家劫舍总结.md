# 打家劫舍系列总结（198 / 213 / 337）

## 一、这类题的统一本质

核心都是：**相邻（或父子）不能同时选，求最大和**。  
本质是一个“**选/不选当前点**”的动态规划。

---

## 二、198 打家劫舍（线性数组）

### 1. 状态定义

- `dp[i]`：考虑下标 `0..i` 这个范围时，能偷到的最大金额。
- 这里的“考虑到 i”只是范围，不代表一定偷第 `i` 家。

### 2. 递推

- 不偷第 `i` 家：`dp[i-1]`
- 偷第 `i` 家：`dp[i-2] + nums[i]`
- 取最大：

`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

### 3. 初始化

- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`

### 4. 遍历顺序

从前往后（因为 `dp[i]` 依赖更小下标）。

### 5. 空间优化

可用两个变量替代数组：

- `prev_max` 表示 `dp[i-2]`
- `curr_max` 表示 `dp[i-1]`

---

## 三、213 打家劫舍 II（环形数组）

环形的关键冲突是：**首尾不能同时偷**。  
把环拆成两个线性问题：

1. 偷 `0..n-2`（包含头，不包含尾）
2. 偷 `1..n-1`（包含尾，不包含头）

答案是两者最大值。

`ans = max(robRange(0, n-2), robRange(1, n-1))`

其中 `robRange` 的逻辑就是 198。

### 常见易错点

- `n=1` 要单独返回 `nums[0]`
- 子区间 DP 时，下标映射要清楚：  
  若 `dp` 是从 `0` 开始的新数组，则访问原数组应写成 `nums[start + i]`

---

## 四、337 打家劫舍 III（二叉树）

数组上的“相邻不能选”变成树上的“父子不能同时选”。

### 1. 树形 DP 状态（后序）

对每个节点返回一个二元组：

- `not_rob`：不偷当前节点的最大值
- `rob`：偷当前节点的最大值

### 2. 转移

设左子树返回 `(l_not, l_rob)`，右子树返回 `(r_not, r_rob)`：

- 偷当前节点：孩子都不能偷  
  `rob = node.val + l_not + r_not`
- 不偷当前节点：孩子可偷可不偷，分别取最大  
  `not_rob = max(l_not, l_rob) + max(r_not, r_rob)`

最终答案：`max(not_rob, rob)`

### 3. 为什么后序遍历

因为当前节点的值依赖左右子节点的结果，必须先算子节点再算当前节点。

---

## 五、系列题一眼识别模板

看到“不能同时选相邻对象 + 求最大收益”，优先想：

1. **定义状态**：`选当前` / `不选当前`
2. **写转移**：当前选与不选分别来自哪里
3. **处理结构**：  
   - 线性：直接 DP（198）  
   - 环形：拆成两个线性区间（213）  
   - 树形：后序返回二元状态（337）

---

## 六、速记版

- 198：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
- 213：`max(rob(0..n-2), rob(1..n-1))`
- 337：每个节点返回 `(not_rob, rob)`，后序合并

一句话总结：**同一题眼，不同结构；核心永远是“当前选不选”的状态转移。**
